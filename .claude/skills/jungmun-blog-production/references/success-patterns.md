# 검증된 경로와 한계

Mac 한국어 Umji 한 현장에서 확인한 성공/실패 기록이다. Windows에도 동일한 검증 기준을 적용하되 실기 성공으로 미리 확대하지 않는다.

1. 사진/GIF가 있다는 것만으로 레퍼런스 일치가 아니다. 집 모양 사진 마스크·크림 여백·짙은 갈색 명조 로고·하단 문구·밝기를 실제로 본다. 원본 구조는 재생성하지 않는다.
2. 전체1800자는 공백·소제목 포함, 줄바꿈·제목·이미지 글자·배너 아래 태그 제외다. 모바일 의미단위 줄바꿈과 문장 뒤 빈문단,30/16 UI 값·핵심단어 굵기를 검사한다. 숫자는 검색 효과 보장값이 아니다.
3. 본문에서 전체 선택 단축키는 사진까지 잡는다. 기존 사진 사이 구간은 첫 문단 Home→마지막 문단 Shift+클릭→shift+End→복사로 선택문을 대조하고 나서 붙여넣는다. 사진 컴포넌트ID가 전후 같아야 한다.
4. 소제목에서 교체하면 일반 문장에 굵기가 상속될 수 있다. HTML에서 font-weight:normal을 명시하고 핵심단어 strong만 남긴다. 빈 태그와 실제 글자의 서식은 구분한다.
5. 확장 첨부의 로컬 권한 실패는 OS 파일선택으로 우회했다. Mac은 slash→PathTextField→Return→열기로 성공했다. Windows는 OS별 별도 처리이며 실제 파일창 관찰이 필요하다. 권한/보안 설정 변경을 자동 해결책으로 삼지 않는다.
6. 화면 밖 사진은 SVG, GIF는 img가 없는 span으로 잠시 보일 수 있다. 인접 문단을 화면에 불러와 실제 URL을 확인한다. 미로딩을 성공이나 유실로 단정하지 않는다.
7. 사진 교체는 대표선택을 해제할 수 있으므로 PNG만 다시 대표로 고른다. GIF 본문 재생과 마지막 배너·전화링크는 각각 확인한다. 전화는 걸지 않는다.
8. 현재 편집 중인 임시글을 다시 누르는 것은 저장복원 증거가 아니다. 임시저장 후 새로고침하고 목록에서 불러와 원고/사진/대표/배너를 검사한다.
9. 파일선택 중 다른 프로필 창으로 전환되면 최신 창 상태를 다시 확인한다. 고정 sleep/이전 인덱스를 누적하지 않는다.
10. 사용자가 줄인 세 간격은 보존한다. 제목→첫PNG 사이 빈 텍스트 컴포넌트 없음, `안녕하세요.`→브랜드 인사 바로 다음 문단, 마지막 문장→배너 빈 문단 최대1개. 현재40px 제목 간격은 이 화면의 관찰값이며 OS 공통 고정값이 아니다. 다른 문장 간격은 줄이지 않는다.
11. 태그15개는 배너 아래16/보통체/3개씩 배치한다. 태그를1800자 검사에 합치면 기존 본문을 잘못 잘라낼 수 있어 마지막 배너 전후로 검사 범위를 나눈다. 본문 해시태그와 발행 등록 태그의 완료 상태를 구분한다.
12. 자산 제작 시간, 업로드/서식/검수, 전체 현장 소요시간을 나눈다. 이미지 제작 약1초 또는 텍스트 생성 화면의 타이머를 전체10분 달성으로 확대하지 않는다.
