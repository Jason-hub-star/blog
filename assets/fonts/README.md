# 한글 폰트

- NanumSquareEB.ttf: 이 작업에서 사용하던 NAVER NanumSquare ExtraBold 원본 파일.
- NanumMyeongjo-ExtraBold.ttf: Google Fonts의 Nanum Myeongjo ExtraBold 원본 파일.
- 출처와 SHA-256은 SOURCES.json, SIL Open Font License1.1 전문/원본 저작권 안내는 OFL.txt에 보존했다. 폰트 파일은 수정하거나 시스템에 설치하지 않는다.
- NanumSquare의 권리자는 NAVER이다. [공식 나눔글꼴 라이선스](https://help.naver.com/service/30016/contents/18088?osType=PC)는 저작권·라이선스 안내와 함께 소프트웨어 번들/재배포를 허용한다.
