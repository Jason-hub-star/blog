# 이어받기

목표·승인 범위 정본은 [STATUS.md](../STATUS.md) 하나다. 현재 단계는 간격/태그 반영과 현장 인계 설정 완료다. 상세 증거는 [마감 기록](../evidence/2026-11-01/spacing-tags-handoff.md).

- 시작 지점: 저장소 루트에서 [아내_시작하기.md](../아내_시작하기.md)를 연다. 현재 Mac 현장 폴더는 `현장작업/2026-11-01_성남_여수동_산들마을아파트`이며 실제 존재한다(로컬/Git 제외).
- 먼저 읽을 것: 시작 안내 → 이 문서 → `.claude/skills/jungmun-blog-production/SKILL.md`.
- 완료: 사용자 세 간격 보존·본문1800자·배너 아래 태그15개·저장복원16조건, 새 현장5/10장 폴더 검사. Codex와 Claude는 같은 정본을 사용한다.
- 공유: 코드0f20aa8 원격main 반영, [Windows/Linux 게이트](https://github.com/Jason-hub-star/blog/actions/runs/41279127201) 모두 성공. 마감 판정 ready-to-share(이번 인계 범위).
- 남은 실증: Windows 로그인된 네이버 업로드/저장복원, 아내분의 첫 신규 현장과 전체10분 계측. 발행 설정의 등록 태그는 공개 발행을 정했을 때 입력한다. 현재 글은 임시저장 상태다.
- 다음 기여/의존성: 새 현장 사진5~10장·사실 메모와 Windows Chrome 연결이 있으면 실제 소요시간을 재서60분→10분 목표를 판정할 수 있다.
- 우회 복귀: 파일창이 다르면 현재 UI를 관찰해 허용 GUI 첨부/chooseFile을 사용하고, 이미 만든 로컬 산출물은 보존한다. UI를 끝낸 뒤 같은 저장복원 검증으로 돌아온다.
- 첫 명령(Windows, 준비된 저장소 루트): `.venv\Scripts\python.exe scripts/check.py`. 처음 받은 컴퓨터는 README대로 `py -3 scripts/setup.py`부터 한다.
